# 会话空间清理

独立工具插件，沿用原空间清理的会话关联语义。仅盘点当前宿主中会话实际关联的 Git worktree，不递归扫描电脑，不读取 5199 的私有数据，也不删除主仓库。

## 使用

1. 宿主需支持 SDK 2.2.0 的 `workspaces` 和后台任务接口。
2. 在自定义插件中心「从本机导入」选择构建产物 `dist/worktree-cleanup-1.0.2.dwp`，核对能力并单独确认受信任本机代码。勾选显示菜单后可从菜单打开。
3. 必需权限：插件本机运行、私有记录读取、会话工作区读取。清理及后台任务均为可选权限；不授予时可只读使用。
4. 「会话工作区」显示关联会话、路径、分支、占用、最后使用时间和保护原因。选择可清理项后先预览、再确认。一次最多 100 个；取消无副作用，预览五分钟内有效且只能使用一次。
5. 「定时清理」默认关闭。明确确认后设置闲置天数（1–365 天）及间隔（1–168 小时），首次执行在一个完整间隔以后。仅自动处理宿主管理的会话 worktree；外部工作区需手动确认。
6. 清理保留分支和会话记录，沿用宿主安全回收流程。不要把 worktree 清理视作未提交文件备份；插件拒绝清理未提交、未跟踪及忽略文件。

## 公共依赖与边界

使用固定 SDK 2.2.0 制品的 `@delivery/plugin-sdk/server`：`host.workspaces.access/list/preview/remove`；页面使用 `host.request` 与主题获取/订阅。策略、记录、确认令牌和界面均在插件中；宿主仅提供通用读取、安全回收及后台调用能力。

后台声明每 60 秒唤醒 `tick`，插件根据持久化策略判断是否到期。需工作台持续运行；关闭页面或隐藏菜单不停止任务，停用、移除、撤权或关闭工作台会停止后续调用。工作台重启后恢复已确认的策略，不补跑错过的每个周期。不触碰其他服务。

宿主在会话/仓库锁下再次检查目录身份、状态、占用、授权和闲置条件。超时或中断显示「待核对」，相关路径暂停自动处理，必须人工检查；不自动重放。手动重新预览并成功清理后解除该路径的暂停。最近 200 条记录保存在插件自身目录，待核对路径单独持久化，移除默认保留数据。

页面跟随宿主主题、支持窄屏；定时策略在插件页面设置，不需要外部服务账号。本机应用不是操作系统沙箱，只应安装可信包。

## 构建和测试

在插件仓库运行 `pnpm build` 生成包含前后端依赖的独立 `.dwp` 包；`pnpm test` 验证授权降级、确认、防重放、策略重载、周期筛选和超时处理。安装时不执行依赖安装脚本，不依赖兄弟仓库源文件。

## 占用统计口径

页面统计会话关联的 Git worktree，包含仍在旧工作台或其他目录中的外部 worktree；以磁盘分配空间（`du -skx`）计量。设置中的存储清理只汇总当前实例管理的缓存、工作区与会话记录，并按文件内容大小计量，因此两处总数不直接可比。外部目录仅展示，并不自动获得清理授权；可清理量还须通过宿主的目录身份、Git 状态和占用检查。
